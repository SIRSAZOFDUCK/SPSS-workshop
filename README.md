# SSC2 SPSS Workshop (Part 2)

Interactive workshop by Saran Shantikumar, 2026. Built with Codex (OpenAI).

The workbook contains worked examples, exercises and downloadable practice data for SPSS 31. It covers data preparation, normality, independent and paired t-tests, Welch ANOVA, comparisons of medians, chi-square tests, linear regression and logistic regression.

## Open the workshop

Open `index.html` in a browser, keeping `assets/` and `downloads/` alongside it. No installation or build step is needed.

The offline copy is available at `downloads/offline-workshop.zip`. Extract it before opening its `index.html`. External reference links require an internet connection.

## GitHub Pages

The files are ready for GitHub Pages. In the repository settings, choose **Pages → Deploy from a branch → main → / (root)**. The `.nojekyll` file allows GitHub Pages to serve the files directly.

## Data and progress

The datasets contain synthetic practice records and may not reflect real clinical associations. The starting SPSS dataset is `downloads/start-here.sav`. A prepared dataset is retained in the repository but is not offered as a download in the student workbook.

Progress is stored in the current browser session. Quiz answers are checked in the browser and are not submitted to a server.

## Validation

The numerical examples were checked using SPSS Statistics 31 on Mac. Navigation, quizzes and progress were checked in a browser. Windows classroom menu interactions remain untested.
